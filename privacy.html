Privacy Policy

Last updated: 2026-11-04

HA Calendar is a personal OAuth client used only by its owner, with the owner's own Home Assistant server, to read the owner's Google Calendar data.

Data accessed

Calendar event details (titles, times, locations) from the owner's Google account, via the Google Calendar API.

How it is used

Events are shown on the owner's home dashboards and displays. Data is used for no other purpose.

Storage and sharing

Access tokens are stored only on the owner's private home server. No data is sold, shared with third parties, or sent to any server other than Google's and the owner's own.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
